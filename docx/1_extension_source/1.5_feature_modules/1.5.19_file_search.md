# 1.5.19 - File search (fd + rg) — moved to pi-kitten

<!-- last-reviewed: 2026-09-28 -->

## Status

**Removed from this repository on 2026-09-28.** The `fd` + `rg` model tools and
the `fileSearchEnabled` preference now live in the
[pi-kitten](https://github.com/xdblue/pi-kitten) package:

| What | Where |
| --- | --- |
| Tool registration, binary resolution, execution, output shaping | `pi-kitten: extensions/file-search/index.ts` |
| Pure argv construction (pattern/glob/path handling, clamps) | `pi-kitten: extensions/file-search/args.ts` |
| The `fileSearchEnabled` preference (`~/.pi/agent/pi-kitten.json`) | `pi-kitten: extensions/file-search/preferences.ts` |
| Full parameter contract | `pi-kitten: docs/file-search.md` |

Why: one source of truth. Two copies of the same tools drift, and pi-kitten is
the installed package that every session loads.

## What changed here

- `extensions/aftc-toolset/file-search/` (2 modules + 2 readmes + the child
  entry stub) was deleted.
- The `createFileSearch(pi)` call and its import were removed from
  `extensions/aftc-toolset/index.ts`.
- `fileSearchEnabled` was removed from `config.ts` and its readme sample.
- The `/file-search-on` and `/file-search-off` commands no longer exist here;
  pi-kitten provides them.

The previous contract (binary resolution order, execution caps, `/file-search-on|off`
semantics, argv safety rules, model guidance) is preserved in pi-kitten's
`docs/file-search.md` and module docstrings.
